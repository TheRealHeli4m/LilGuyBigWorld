# Little Liam

Little Liam is a game where you control a tiny character named Liam across a field (table) of dangers to collect coins.

## How to Play

* **Move:** `A` and `D` (to move left and right respectively)
* **Jump:** `Spacebar`

* Avoid various dangers, get to the end and see how many coins you got!

## Installation & Running

Simply visit our game on [itch.io](https://emsch270.itch.io/lil-liam) and play it on the web!
